# Enclosure

## Starting reference

A printable box exists specifically for the Freenove ESP32-WROVER CAM:

- [Printables model 803138](https://www.printables.com/model/803138-esp32-wrover-cam-box-freenove/)
- [Thingiverse model 6528728](https://www.thingiverse.com/thing:6528728)

It can provide useful internal board geometry, but it is not yet a complete outdoor doorbell enclosure.

## Required doorbell changes

- External momentary-button opening and retention
- Wall mounting
- Downward or sealed power entry
- Rain hood and protected lens opening
- Drainage and condensation management
- Service access without removing the wall mount
- Suitable camera viewing angle
- Outdoor material and print-orientation guidance

## Licensing and attribution

Do not copy an external STL or editable source into this repository until its exact license and author attribution have been recorded. Third-party enclosure files do not automatically fall under this repository's MIT License.

Create a dedicated subdirectory for each imported design containing:

- Original source URL
- Author/designer
- Original license
- Unmodified source file
- A change log for derivatives
- The required attribution notice

## Validation status

No enclosure in this repository should be described as weatherproof until a printed prototype passes fit, spray, drainage, heat, and sustained-operation tests.

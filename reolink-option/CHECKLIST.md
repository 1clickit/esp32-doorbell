# Reolink option checklist

## Before purchase

- [ ] Confirm the intended model is Reolink Video Doorbell WiFi D340W
- [ ] Confirm a Reolink plug-in chime is included or purchase a compatible one
- [ ] Locate the existing transformer
- [ ] Confirm transformer output is 12–24 VAC, 50/60 Hz
- [ ] Record transformer VA rating; 16 VAC/30 VA is the compatibility reference
- [ ] Confirm the current chime is mechanical
- [ ] Confirm the system has one front button and one chime
- [ ] Confirm adequate 2.4 GHz or 5 GHz Wi-Fi at the door
- [ ] Confirm the mounting plate or wedge covers the existing wall opening

## Before installation

- [ ] Original doorbell and chime work
- [ ] Original connections photographed
- [ ] Correct breaker identified
- [ ] Reolink jumper cable present
- [ ] Reolink chime present
- [ ] Suitable exterior sealant available
- [ ] Small screwdriver and voltage meter available

## After installation

- [ ] Stable boot with no restart loop
- [ ] Reolink chime paired and tested
- [ ] Phone notification tested
- [ ] Live and recorded video tested
- [ ] Night image tested
- [ ] Home Assistant local integration tested
- [ ] Mechanical chime is silent with no buzzing
- [ ] Mounting and weather sealing inspected
- [ ] Rollback parts retained and labeled
